# Zephyr's Lab

Personal technical blog. Notes on agents, kernels, and the systems in between.

**Live**: https://gzb1128.github.io (待部署)

## Stack

- **Framework**: Astro 5
- **UI**: React (interactive components only) + Tailwind CSS 4
- **Content**: MDX
- **Code Highlighting**: Shiki (dual-theme)
- **Math**: KaTeX
- **Diagrams**: Mermaid
- **Search**: Pagefind
- **Comments**: Giscus
- **Hosting**: GitHub Pages + GitHub Actions
